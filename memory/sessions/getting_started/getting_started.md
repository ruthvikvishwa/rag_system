The RAG (Retrieval-Augmented Generation) system is a framework for building
AI assistants that can answer questions based on your documents.

**How it works:**
1. You add your documents (PDFs, MD files, etc.)
2. The system chunks them into smaller pieces
3. It creates vector embeddings for each chunk
4. When you ask a question, it finds relevant chunks
5. It generates an answer based on those chunks

**Why use it:**
- Gives your LLM access to your documents
- Only shows relevant context (not everything)
- Handles multiple document types
- Supports PDFs with tables, images, etc.
